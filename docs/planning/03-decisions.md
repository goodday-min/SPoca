## 3. 시계열 데이터
- 주제: **Spoca 학습 기록**, 형식 `(date, value, memo)`
- `value` = 그날 패스한(외운) 단어 수, `memo` = 자유 메모(**최대 200자**)
- **날짜당 기록 1개**(date 유일, 중복 시 거부), 문서 ID는 자동 ID
- 100일 이상 샘플 데이터는 **시드 스크립트 1회 실행**으로 입력(방법은 README에)
- 이후 데이터는 복습 완료 시 자동 기록 + CRUD 제공
- 복습 대상이 없는 날·복습하지 않은 날은 기록을 만들지 않는다(0으로 자동 기록 안 함)
- 요약: 기간·개수·평균/최대/최소·최근 추세, **전체 + 최근 7일** 두 가지. 추세는 최근 7일 평균 vs 이전 7일 평균, ±10% 이내 유지 / 초과 증가 / 미만 감소 / 비교 불가

## 4. Spoca 기능
### 4-0. 단어장 등록·관리
- 등록 방법 2가지: **책 스캔**(인식된 단어는 확인 없이 즉시 등록) / **직접 입력**. 항목: 단어 + 뜻 + 예문(선택). 뜻이 없으면 비워 두고 등록.
- 등록일 직접 지정(오늘/내일/날짜 선택, 과거 불가, 기본 오늘)
- **수정은 단어·뜻·예문만** 가능. 단계·상태·등록일은 직접 수정 불가(복습 결과로만 변경). 삭제는 바로 삭제.
- 목록 정렬: 최신 등록순 / 단계순 (검색·필터 없음)
- 단어 화면: 목록과 등록 분리, 등록 화면에도 하단 탭 바 표시, 수정은 목록 위 팝업

### 4-1. 간격 반복 복습
- 에빙하우스 망각곡선 기반. 기준 시점 = **등록일**, 누적 계산: **New 당일 → V1 1일 → V2 3일 → V3 7일 → Master 30일**. 최대 5번.
- **탭 안 한 단어 = 패스(외움)**, 탭한 단어 = 못 외움(다음 단계). Master까지 못 외우면 "못 외움"으로 종료.
- 복습은 하루 한 번. 복습 대상: 현재 단계의 복습일이 오늘이거나 지난 단어. 놓친 단어는 가장 낮은 놓친 단계로 한 번만 묻는다. 다음 단계 일정은 등록일 기준 그대로.
- 복습 화면: 2열 그리드, 학습 방향 전환(영어→한글 / 한글→영어), 단어 칸마다 발음 듣기 아이콘, 탭하면 뜻만 표시 + "다시복습" 태그, **탭한 칸은 취소 불가**, 어느 방향에서든 탭 = 못 외움, 방향을 바꿔도 탭 표시 유지
- 복습 완료 시 그날 패스한 단어 수가 학습 기록 `value`로 자동 기록(기존 메모 유지). 결과 화면: N개 외움 / 오늘 복습 / 다시 복습 / N일 연속 / 다시 복습할 단어 / 홈으로
- **연속 학습 일수**: 복습을 완료한 날 기준. 복습 대상이 없는 날은 끊기지 않고 그날 바로 +1. 대상이 있는데 안 한 날은 끊김. 홈에는 어제까지의 연속 일수를 보여주고, 복습을 마치는 즉시 오늘이 더해진 숫자로 바꾼다. **복습 완료 때 계산해 저장하고, 조회 API를 따로 만든다**(경로 제안 `GET /api/streak`, 저장 위치·최종 경로는 구현 시 확정).

### 4-2. 책 사진 영어 대화
- 책 사진 **최대 3장**(촬영 또는 갤러리, 장별 삭제 가능) → 합쳐서 인식 → 난이도 Beginner/Advanced → 100% 영어 음성 대화
- 인식 후 "스캔 완료 · 문장 N개 인식됨", 실패 시 "글자를 읽지 못했어요" + 다시 찍기
- 종료: 종료 버튼 또는 AI 마무리. 대화 내용은 단어 추출에만 쓰고 **저장하지 않는다**.
- 나온 단어는 단어장에 자동 등록, 종료 후 **단어장 목록으로 이동**하고 "방금 등록" 표시(목록을 처음 열 때만)
- 영어 대화는 **홈에서만** 진입(하단 탭 없음)
- 음성을 지원하지 않는 브라우저에서는 "이 브라우저는 음성을 지원하지 않아요" 안내만 표시

### 4-3. 리포트
- 하단 탭 "리포트", 위쪽 "학습 기록" 버튼으로 학습 기록 화면 진입 (리포트 화면을 만들기 전까지는 하단 탭 "리포트"를 학습 기록 화면에 임시 연결)
- 기간 보기 3가지: **최근 7일(기본) / 월별 / 전체**. 요약 카드(개수·평균·최대·최소·기간), **추세는 7일 보기에서만**
- 일별 그래프는 기간을 따라가며 7일·월별은 막대, **전체는 선 그래프**
- 단계 분포(현재 상태): 복습 중(New/V1/V2/V3/Master 개수) + 끝난 단어(외움/못 외움 개수)
- 추가 지표(보너스): 최장 연속 일수, 요일별 평균. v1의 "대화 하이라이트"는 두지 않는다.

## 5. AI 코칭 채팅 (하단 탭 "AI 비서" → 구현에서 "AI코치"로 명칭 변경)
- `/api/chat`: 요약 조회 → 시스템 프롬프트 삽입(컨텍스트 주입) → GPT 호출 → 대화 자동 저장(conversations)
- 화면: 맨 위 요약 한 줄, 위쪽 "새 대화"(틸 테두리) · "지난 대화"(산호 채움, 아래에서 올라오는 패널), 예시 질문 3개("최근 7일 어땠어?", "잘 외운 날은?", "앞으로 어떻게 할까?"), 입력창 아래 "AI가 생성한 답변이에요", 로딩 말풍선 "답변을 만드는 중…" + "서버를 깨우는 중이라 조금 걸려요". 지난 대화 삭제는 바로 삭제.

## 6. 학습 기록 화면
- 리포트에서 진입. 최신 날짜가 위, "더 보기"로 이어서 불러옴. 추가·수정은 팝업(날짜·외운 단어 수·메모), 삭제는 바로 삭제, 이미 있는 날짜는 "이미 기록이 있어요"로 거부.
- 맨 위 요약 카드(전체 / 최근 7일 전환). 위쪽 "내보내기"(CSV/JSON 선택, 산호 채움) · "+ 기록"(틸 테두리). (구현에서는 CSV·JSON 버튼 2개로 변경)
