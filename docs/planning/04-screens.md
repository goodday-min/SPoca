> 구현된 실제 화면은 README의 "화면" 섹션 스크린샷과 배포 주소(https://spoca-ecru.vercel.app)에서 볼 수 있다.
> 구현 중 바뀐 부분(AI코치 명칭, 단어 화면 개편, CSV·JSON 버튼 등)은 `05-task.md`의 "확정된 결정" 표가 최신이다.

## 확정된 사항
- 모바일 우선(반응형), 홈 화면 + 하단 탭 바 구조
- 디자인: v1 스타일 확정 — 산호 + 틸 (v1 스토리보드 PDF 기준 진한 톤 사용), 폰트 Baloo 2(로고) + Noto Sans KR(본문)
  - 참고: `SPoca_스포카 스토리보드_v1.pdf`. 마스코트는 홈 상단 큰 크기(위치 확정). 표시 방식·모양 수정은 나중에 한다(보류).
- 화면 위쪽 버튼 색 (확정)
  - 다른 화면을 열거나 보러 가는 버튼("학습 기록", "지난 대화", "내보내기" 등): 산호색 채움. 이전보다 20% 연하게 `#D3694B`(이전 `#C8431E`)
  - 만들거나 추가하는 버튼("+ 기록", "새 대화", "단어 등록" 등): **진한 틸색 테두리 `#136F68`** (틸은 연하게 하지 않는다)
  - 모든 화면의 위쪽 버튼에 동일하게 적용

### 단어 화면 (확정)
- 등록과 목록을 분리
  - ① 단어장 목록 (하단 탭 "단어"): 단어 수, 정렬(최신 등록순/단계순), 단계 배지, 수정·삭제 아이콘, "+ 단어 등록" 버튼
  - ② 단어 등록 ("+ 단어 등록" 탭 시): 직접 입력/책 스캔 전환, 단어·뜻·예문(선택), 등록일 선택(오늘/내일/날짜 선택), 등록하기 버튼, 왼쪽 위 뒤로가기
- 등록 화면에서도 하단 탭 바를 보이게 한다
- 삭제: 삭제 아이콘을 누르면 바로 삭제
- 수정: 한 단어씩 건별로, 목록 위 팝업 창
  - 수정 가능 항목은 단어, 뜻, 예문뿐. 단계와 상태는 임의로 수정할 수 없고 복습 결과로만 바뀐다. 등록일도 수정 항목이 아니다.
  - "외움 → 못 외움 시 다시 시작" 같은 예외 기능은 두지 않는다.

### 홈 화면 (확정)
- 홈에 넣는 항목: 오늘의 복습, 영어 대화 시작, 코칭 채팅 바로가기
- 영어 대화는 홈에서만 연결하고 하단 탭에는 두지 않는다. 단어장에 무게를 둔 앱이다.
- 하단 탭의 대화 탭은 "코칭 채팅(AI 비서)"으로 한다 (구현에서 "AI코치"로 명칭 변경)
- 인사말("안녕, ○○님")과 부모 모드 링크는 현재 넣지 않는다
- 다크 모드 토글: 맨 위 왼쪽에 해/달 아이콘 (오른쪽 위는 "N일 연속" 배지)
- "N일 연속" 배지를 넣는다
  - 기준: 복습을 완료한 날
  - 복습 대상이 없는 날은 연속이 끊기지 않고, 그날 바로 연속 일수를 1 늘린다
  - 복습 대상이 있는데 하지 않은 날은 연속이 끊긴다
  - 복습 전에는 어제까지의 연속 일수를 보여주고, 복습을 마친 즉시 오늘이 더해진 숫자(예: 7일 → 8일)로 바꾼다
- 오늘의 복습 카드 상태
  - 복습할 단어가 있을 때: 개수 + "복습 시작"
  - 오늘 복습을 마쳤을 때: "오늘 복습 완료" + 외운 단어 수 (시작 버튼 없음)
  - 복습 대상이 없을 때: "오늘 복습할 단어가 없어요" 안내 + "단어 등록하러 가기"
- 학습 기록 화면은 리포트 화면 안의 버튼으로 들어간다

### 복습 화면 (확정)
- 구성: 상단 "오늘의 복습 + 개수", 학습 방향 전환(영어 → 한글 / 한글 → 영어), 안내 문구, 단어 칸 2열 그리드, 하단 "복습 완료 · N개 다시 복습" 버튼, 하단 탭 바
- 각 단어 칸에 발음 듣기 아이콘 (Web Speech API)
- 탭하면 그 자리에서 뜻만 펼쳐지고 "다시복습" 태그가 붙는다 (예문은 보이지 않음)
- 한글 → 영어 방향: 칸에 뜻(한글)을 보여주고, 탭하면 영어 단어가 나온다
- 한 번 탭해서 한글/영어가 나온 칸은 취소할 수 없다
- 어느 방향에서든 탭하면 못 외운 것으로 처리한다. 단어당 단계는 하나만 유지한다.
- 복습 도중 방향을 바꿔도 탭한 표시는 유지한다

### 복습 결과 화면 (확정, 초안 그대로)
- 항목: "N개를 외웠어요"(크게), 오늘 복습 개수, 다시 복습 개수, "N일 연속!"(복습 완료 직후 갱신된 숫자), 다시 복습할 단어 목록(단어 + 뜻), "홈으로" 버튼, 하단 탭 바

### 학습 기록 화면 (확정)
- 리포트 화면의 버튼으로 진입. 날짜 · 외운 단어 수 · 메모를 목록으로 보여준다.
- 목록은 최신 날짜가 위. 맨 아래 "더 보기" 버튼으로 이어서 불러온다.
- 기록 추가·수정: 목록 위 팝업 창 (입력 항목: 날짜, 외운 단어 수, 메모)
- 삭제: 삭제 아이콘을 누르면 바로 삭제
- 이미 기록이 있는 날짜로 저장하면 "이미 기록이 있어요" 안내를 띄우고 저장하지 않는다 (날짜당 기록 1개)
- 요약 표시: 이 화면 맨 위에 요약 카드(전체 / 최근 7일 전환, 기간·개수·평균·최대·최소·최근 추세). "기간"은 시작일~종료일 날짜 범위, "개수"는 별도 항목.
- 코칭 채팅 화면 맨 위에도 같은 요약을 한 줄로 작게 보여준다 (제출 스크린샷용)
- 위쪽에 "내보내기" 버튼 → CSV / JSON 선택 메뉴 (보너스) (구현에서는 CSV·JSON 버튼 2개로 변경)

### 코칭 채팅(AI 비서) 화면 (확정)
- 하단 탭 "AI 비서"로 진입 (구현에서 "AI코치"). 맨 위에 요약 한 줄(전체 기간·평균 / 최근 7일 추세)
- 위쪽에 "새 대화" 버튼. 대화는 보내면 자동으로 저장된다.
- "지난 대화" 버튼: 지난 대화 목록을 채팅 화면 위로 아래에서 올라오는 패널로 연다. 항목을 누르면 그 대화를 불러온다.
- 대화 목록 삭제: 삭제 아이콘을 누르면 바로 삭제
- 첫 화면에 예시 질문 버튼: "최근 7일 어땠어?", "잘 외운 날은?", "앞으로 어떻게 할까?"
- 입력창 아래에 "AI가 생성한 답변이에요"를 항상 표시
- 답변을 기다리는 동안 로딩 말풍선에 "답변을 만드는 중…" + "서버를 깨우는 중이라 조금 걸려요"를 표시

### 영어 대화 화면 (확정)
- 홈의 "영어 대화 시작"에서만 진입 (하단 탭 없음)
- 책 스캔: 카메라 촬영과 갤러리 선택 둘 다 가능 (v1과 동일). 사진은 최대 3장까지 모을 수 있고 "페이지 추가" 버튼으로 추가하며, 잘못 찍은 장은 뺄 수 있다. (PRD F7 반영)
- 스캔 후 표시: 사진 썸네일 + "스캔 완료 · 문장 N개 인식됨" (여러 장이면 합산). 인식 실패 시 "글자를 읽지 못했어요" + "다시 찍기" 버튼.
- 난이도 선택: Beginner(쉬운 표현·짧은 문장) / Advanced(긴 문장·다양한 어휘), "AI와 대화하기" 버튼으로 시작
- 대화 화면은 v1 그대로: AI와 내 말풍선(영어 자막), 마이크 버튼, 듣는 중 파동 표시, 상단 경과 시간
- 대화가 끝나면 단어장 목록 화면으로 이동하고, 방금 등록된 단어에 "방금 등록" 표시를 한다. 이 표시는 단어장 목록 화면을 처음 열 때만 보이고, 이후에는 사라진다.

### 리포트 화면 (확정)
- 하단 탭 "리포트"로 진입. 위쪽 오른편에 "학습 기록" 버튼(학습 기록 화면으로 이동)
- 기간 보기 3가지: **최근 7일(기본) / 월별 / 전체**
  - 요약 카드: 개수, 평균, 최대, 최소, 기간(시작일~종료일)
  - 최근 7일 보기에서만 추세(증가/감소/유지/비교 불가)를 표시한다. 월별·전체 보기에서는 "추세는 7일 보기에서" 안내로 대신한다.
  - 월별 보기: "< 2026년 10월 >" 화살표로 이전/다음 달 이동, 매월 1일~말일 기준. 기록이 없는 날은 그래프에서 빈 칸.
- 일별 외운 단어 수 그래프: 요약에서 고른 기간을 따라간다. 최근 7일·월별은 막대 그래프, **전체는 선 그래프**.
- 단어 단계 분포: 기간 선택과 상관없이 항상 현재 상태를 보여준다. 두 묶음 — "복습 중"(New/V1/V2/V3/Master 단계별 개수), "끝난 단어"(외움/못 외움 개수).
- 추가 지표 2개(보너스): 요약 카드 아래 작은 카드로 "최장 연속 일수"와 "요일별 평균 외운 단어 수(작은 막대 그래프)"
- v1의 "이번 주 대화 하이라이트"는 두지 않는다(영어 대화 내용을 저장하지 않으므로).

## 화면 목록 (확정)
- 공통: 홈 (복습 있음 / 복습 완료 / 대상 없음 3상태)
- 단어: 단어장 목록, 수정 팝업, 단어 등록(직접 입력 / 책 스캔), 영어 대화 직후 목록("방금 등록")
- 복습: 오늘의 복습(두 방향), 복습 결과
- 학습 기록: 기록 목록·추가·수정·삭제, 요약 표시, 내보내기
- 코칭 채팅(AI 비서): 새 대화(예시 질문), 대화 중(로딩), 지난 대화 패널
- 영어 대화: 책 스캔(최대 3장), 인식 후 난이도 선택, 인식 실패, 음성 대화
- 리포트: 기간 요약(3가지 보기), 일별 그래프, 단계 분포, 추가 지표, 학습 기록 버튼

## 하단 탭 (확정)
홈 / 단어 / 복습 / AI 비서(→AI코치) / 리포트
